# Atividades de Algoritmos e Estruturas de Dados

Este repositório reúne exercícios e o trabalho final desenvolvidos durante a disciplina de Algoritmos e Estruturas de Dados do curso de Ciências da Computação, utilizando a linguagem Java.

## Conteúdos praticados durante a disciplina

- Listas estáticas e encadeadas.
- Pilhas e filas.
- Árvores binárias e árvores n-árias.
- Tabelas de dispersão (Hash).
- Algoritmos de ordenação (Bubble Sort, Quick Sort e Merge Sort).
- Algoritmos de busca sequencial e binária.
- Árvores binárias de busca.
- Operações de inserção, consulta e exclusão em estruturas de dados.

## Observações

- Algumas atividades desenvolvidas durante a disciplina não estão presentes neste repositório.
- Os enunciados das atividades não estão incluídos junto aos arquivos, exceto pelo trabalho final.
